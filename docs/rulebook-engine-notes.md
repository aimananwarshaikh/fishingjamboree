| 2026-11-14 | Server errors: one room cannot stop the others (review P2-4) | Server only; no engine or rule change. `ServerCore.tick` runs each room on its own: a room that throws while its timers run (turn timer, grace, lobby seats, idle deletion) is **closed at once**, because it would throw again on every tick. | 2026-11-14 | Saving rooms: a restart does not end games (review P2-5) | Server only; no engine, rule or protocol message change. With `ROOMS_DIR` set the server saves each room as one JSON file (`<CODE>.json`) after every change and restores all of them on start; unset, rooms live in memory as before (logged at start). What is saved: code, status, host, `rev`, the room's timers, seats (name, token, `left`, `away`, `removed`, reconnect budget left, counted as if a running grace ended at the save) and the game's replay log plus its current state. No clock times: a restored room starts with **nobody connected**, as if everyone had dropped when the server started, so the empty-room rules decide what follows (nothing happens until someone rejoins; then a whole turn on the timer and the others' graces from their budgets; a fresh lobby grace; deleted after 30 minutes if nobody comes back). | 2026-11-14 | Golden Hook Awards: built (B1b) | Rule change (designer's decisions in `docs/bonus-awards.md`; rulebook "End of the game"). At setup the engine draws 2 awards (2 players) or 3 (3–4) from `content/awards.json`: uniformly among every set with no conflicting pair and a combined amount within `budget` ($900), then shuffled for the reveal order. The draw uses its own RNG stream (seed + a fixed suffix), so it changes no die, deck or turn order.
